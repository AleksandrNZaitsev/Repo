"Реализация рутины.

Программа состоит из 3-х файлов: Анализатор, config и run, а также папок

Программа анализирует csv файлы в папке data и выводит в отчет консолидированную информацию о продажах (с размещением итогового файла report в папке report)

При возникновении ошибок при обработке файлов, программа продолжает работать, список ошибок заносится в файл log в соответствующей папке.
